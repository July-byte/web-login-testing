# Test Plan - login functionality

## 1. Object of testing
Login form functionality.

## 2. Features to be tested
- Username field
- Password field
- Login button
- Authentication behavior
- Error messages
- Redirect after login
- Logout behavior

## 3. Features not to be tested
- Perfomance testing
- Load testing
- Deep security testing

## 4. Testing types
- Functional testing
- Negative testing
- UI testing
- Basic security testing

## 5. Risks
- Missing validation
- Incorrect error handling
- Session mismanagement
- Information disclosure

## 6. Entry criteria
- Application is accessible
- Login page loads correctly

## 7. Exit criteria
- All critical and major bugs are fixed
- All tests cases executed
